브라우저는 잘못된 HTML을 자동으로 보정할 수 있습니다. 따라서 미리보기 DOM 구조를 함께 확인하는 것이 중요합니다.

    최근 성능 결과
    
              
    
            
    
          
    
          
    
            
    실행된 케이스 기록
    
            
      
          
      
        
      
      
      

      
      
        
      
          
      
            
      개념 지도
      
            
      미니 React를 이해하려면 이 흐름이 잡혀야 합니다
      
          
      
          
      
            발표할 때 아래 개념 카드를 위에서 아래 순서로 설명하면 흐름이 자연스럽습니다.
          
      
        
      

        
      
          
      
            
      1. 실제 DOM
      
            
      
              브라우저가 화면을 그리는 실제 객체입니다. 직접 수정하면 layout 계산과 paint
              비용이 커질 수 있습니다.
            
      
          
      
          
      
            
      2. Reflow / Repaint
      
            
      
              크기와 위치가 바뀌면 Reflow, 색과 배경이 바뀌면 Repaint가 발생합니다. 실제
              DOM 조작이 비싼 이유를 설명할 때 핵심입니다.
            
      
          
      
          
      
            
      3. Virtual DOM
      
            
      
              실제 DOM 구조를 가볍게 표현한 JavaScript 객체 트리입니다. 메모리에서 빠르게
              비교할 수 있습니다.
            
      
          
      
          
      
            
      4. DOM → Virtual DOM
      
            
      
              `nodeType`, `tagName`, `attributes`, `childNodes`를 읽어 Element와 Text
              노드로 변환합니다.
            
      
          
      
          
      
            
      5. Diff 5대 케이스
      
            
      
              노드 추가, 노드 삭제, 태그 교체, 텍스트 변경, 속성 변경. 이 데모의 핵심
              판별 기준입니다.
            
      
          
      
          
      
            
      6. Patch
      
            
      
              Diff 결과를 실제 DOM에 반영하는 단계입니다. 전체 재생성이 아니라 바뀐 위치만
              찾아 수정합니다.
            
      
          
      
          
      
            
      7. State History
      
            
      
              각 Patch 이후 Virtual DOM을 저장해두고, 뒤로가기와 앞으로가기로 특정 상태로
              이동합니다.
            
      
          
      
          
      
            
      8. MutationObserver
      
            
      
              브라우저가 실제 DOM 변화 자체를 감지하는 API입니다. 이 데모에서는 실제 영역의
              변화를 로그로 보여줍니다.
            
      
          
      
          
      
            
      9. React와 연결
      
            
      
              상태가 바뀌면 새 Virtual DOM을 만들고, 이전 Virtual DOM과 비교하여 필요한
              DOM만 바꾼다는 점에서 같은 철학을 가집니다.
            
      
          
      
        
      
      
      

      
      
        개발자 도구 콘솔을 열어두면 Patch와 MutationObserver 로그를 한글로 함께 볼 수
        있습니다.
